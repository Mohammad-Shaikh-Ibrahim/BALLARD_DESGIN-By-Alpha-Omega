# Ballard Desgin

A modern and interactive landing page for Ballarad Design, built using HTML, CSS, and JavaScript. The content—such as project details, images, and service descriptions—is dynamically loaded from a JSON file, making updates easy and flexible. The design features a clean layout, creative visuals, and smooth transitions to reflect the brand's creative identity. Fully responsive and optimized for a great user experience across all devices.
